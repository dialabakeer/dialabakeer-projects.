
# 🌱 Smart Plant Watering System

A Java-based system that predicts plant watering needs using a Perceptron model and Simulated Annealing optimization.

## ✨ Features

* Plant watering prediction
* Perceptron-based classification
* Simulated Annealing optimization
* Intelligent watering decisions

## 🛠️ Technologies

Java · Perceptron · Simulated Annealing
